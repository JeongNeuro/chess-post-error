# **논문 결과를 낸 환경에서 `pip freeze > requirements.lock` 를 받아
#   같이 올릴 것.** 원 분석 환경의 표본 파일 메타데이터에 따르면
#   그 환경은 pyarrow 25.0.1 / pandas 3.0.2 였다. (그 표본 파일 자체는
#   배포하지 않는다 — README 의 *The player sample* 참조.)
# ─────────────────────────────────────────────────────────────
