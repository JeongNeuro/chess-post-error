# Analysis environment
#
# ★ Read this ─────────────────────────────────────────────────
# An earlier version of this file claimed to pin "the versions that
# produced the reported results". It did not. Every constraint was a
# lower bound (>=), so any later version satisfied it. The one pin,
# python-chess==1.999, is a shim that forwards to `chess`, so the
# package actually imported was left unpinned — and `chess` changes the
# return type of chess.between() and others between versions, which
# src/see.py depends on.
#
# What follows is a combination the pipeline has been confirmed to run
# under. **Run `pip freeze > requirements.lock` in the environment that
# produced the reported results and commit that alongside this file.**
# Metadata in the original sample files records that environment as
# pyarrow 25.0.1 / pandas 3.0.2. (The sample files themselves are not
# distributed — see *The player sample* in the README.)
# ──────────────────────────────────────────────────────────────

chess==1.11.2            # (the old python-chess==1.999 is a shim for this)
duckdb>=0.9,<2           # scanning the archive shards
pandas>=2.2,<4
pyarrow>=14,<26
numpy>=1.24,<3
statsmodels>=0.14        # mixed-effects model in src/analysis.py (pulls in scipy)

# ── Optional ──────────────────────────────────────────────────
# Stockfish is an executable, not a Python package. It is needed only
# for the complexity validation (run.py cx). See docs/environment.md.

# ── Deliberately absent ───────────────────────────────────────
# An earlier version listed mne, scikit-learn, scipy, requests and
# zstandard. No file in this repository imports any of the five. The
# flanker comparison (src/flanker.py) reads the derivatives published with
# OpenNeuro ds004883 and needs none of them either.
#
# matplotlib is absent too. This repository produces the statistics and
# stops there; it does not draw the figures. Every plotted value is a row
# in one of the CSVs under data/derived/, so the drawing can be done with
# whatever tool you prefer.
